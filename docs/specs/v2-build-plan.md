### 1.1 Definition of done

Wave 1 package: (a) every owned file implemented - no `NotImplementedError` left in owned source; (b) the rows of T2 section 5 that name your modules, the T2 section 15 row of your lane, and every test file listed in your brief exist and pass; (c) `npx eslint <your paths> --max-warnings 0` clean; (d) `npm run typecheck` reports no error **in files you own** (errors elsewhere: list them in notes, do not fix); (e) `npx vitest run --project <main|renderer|integration|security> <your paths>` green, except tests that fail **solely** because another package's Wave 0 stub still throws `NotImplementedError` or because `compose()` is not wired yet (integration tests before `V2-W2-01`) - list those under `BLOCKED-BY <package id>`; never skip, `.only`, delete or weaken them, never make them conditional on the machine, and never write a private re-implementation of another package's module longer than about 50 lines; (f) the coverage thresholds of TS 13 + T2 13 for your files (the T2 13 safety-critical set is 100 % lines / 95 % branches / 100 % functions per file); (g) the ledger v2 and the T8/T9 guards are active for every test you own (they are global; you do not disable them); (h) notes file written.
