# v2 Wave-0 seams (V2-W0-scaffold)

Status: frozen with Wave 0 (2026-09-28). Author: `V2-W0-scaffold`. Companion of `docs/specs/v2-contracts.md` (C2) and
`docs/specs/v2-build-plan.md` (build plan, section 3). Everything listed here is an exported v2 signature that is **not** a C2
block, plus every W0 type refinement made only to compile, every "v1 remnant", and every v1 test edit W0 made.
C2 blocks themselves are not repeated: they are in their target files verbatim, marked `[V2 ADD]` / `[V2 CHANGE]`.

Rule for Wave 1 (build plan 1.9): every name and shape below is frozen. A needed change is a `REQUESTS` entry to the
orchestrator, never a local edit.

## 0. Conventions

- **Stub body.** A Wave-0 member throws `NotImplementedError(owner, member)` from `src/main/notImplemented.ts`:
  `export class NotImplementedError extends Error { constructor(readonly owner: string, readonly member: string) }` and
  `export function notImplemented(owner: string, member: string): never`. Owner ids are the package ids of build plan 4
  (`V2-W1-01-db` ... `V2-W1-12-renderer-settings`). Modules load at run time; only calling a new member throws.
  `register.ts` maps a throwing handler to `INTERNAL`, so the 24 new IPC channels answer `INTERNAL` until their owner lands.
- **Factories** return objects whose members throw; `export declare function` blocks of C2 became real functions with a
  throwing body and the parameter list verbatim (`// eslint-disable-next-line @typescript-eslint/no-unused-vars`, or a
  `/* eslint-disable ... */` / `/* eslint-enable ... */` pair around multi-line signatures).
- **Fail-closed boot values** where a stub feeds v1 code: `AppHealth.updatesAvailable=false`, `voice.status='off'`,
  `auto.state='off'`, `llm.quota=null`; the tool gate's `waAvailable()` answers `false`; `FEATURE_GATES` all `false`
  (incl. `voicePassed`, D-068); proposal provenance defaults (below); the v1 gate exposes only the two calendar tools.
