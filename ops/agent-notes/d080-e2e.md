## Problem found first: the e2e S-CONSOLE seam could not prove (a) or (c)
The e2e build's console recorder (compose.ts) only pushed the argv and returned nothing = an UNTRACKED console (d080-cli-main kept it
so on purpose so cli-connect (3) stays unchanged). Untracked => cli:signIn opens no session, never re-tests, and the env/cwd the console
would get is not observable. So "when the fake console exits the app re-tests automatically" and "the agy console runs with the
isolated profile env" were untestable from tests/e2e alone.

Decision (minimal, additive, e2e-only, OUTSIDE my owned paths - flagged for the orchestrator):
- `src/main/testSeams.ts`: optional `Seams.consoleDir` = `WCA_CONSOLE_DIR` (absolute drive path only, no UNC / relative / `..`;
  behind the same two locks as every seam: packaged or non-e2e build => null). Unit test added FIRST in `testSeams.test.ts` (red, then
  green).
- `src/main/compose.ts` e2e branch only: with `consoleDir` set the recorder still pushes the argv (so `__wcaTest.consoles()` is
  unchanged) AND writes `console-<n>.json` = {argv, cwd, env} (what production would have spawned; nothing is spawned) and returns
  `{ exited }` resolving when `console-<n>.exit` appears (200 ms poll, unref'd) or the quit began (`lifecycle.closing`). Without
  `WCA_CONSOLE_DIR` the recorder is exactly the old untracked one. Production path (`createOpenVisibleConsole`) untouched.
- The frozen `__wcaTest` facade (TESTS 4.2, "exactly eleven hooks") was NOT widened: the spec reads the json files and "closes" the
  console by writing the .exit file.
- `tests/fakes/fake-agy.mjs` + `.types.ts`: optional state `rejectedModels: string[]`. A run whose `--model` is listed prints the
  1.2.16 refusal SHAPE (stderr `error: invalid model selection (--model "X"): ...`, an error `result` as the FIRST stdout event with
  the captured keys, no init, exit 1), no violation. Only the prefix is from the capture; the rest of the wording is marked ASSUMED.
  Needed because after the D-080 fix the app never sends `--effort` with a suffixed slug, so the fake had no way left to refuse a model.
