## Key design choices in the spec (and why)
- Fakes are spawned with system `node.exe` and a `--fake-end` separator: the app's env is an allow-list, so a fake cannot receive its own config by env; everything after `--fake-end` is exactly the production argv, which makes the argv literal tests trivial and exact.
- Fake CLI rejects unknown flags like the real CLI and treats `--permission-prompts` as unknown below 2.1.259: this catches builder typos and a missing version gate.
- Fake whisper picks the transcript by WAV duration; the synthetic Ogg generator emits DTX-silence of exact durations, so determinism does not depend on decoder output for silence.
- Fake calendar gets an `onBeforeCall` probe so I8 ("pre-write state stored BEFORE the write") is proven against the live DB at the moment of the call.
- Ledger v2 adds global never-delete, never-foreign, media and job-journal rules so any test can fail on those properties, as in v1.
- E2E reaches auto mode only through UI (three approvals, scripted native dialog, three shadow decisions, End trial); no policy seeding seam.
- `WCA_CLI_CMD`/`WCA_WHISPER_CMD` accepted only for node.exe + a file under `tests\fakes\`; in e2e mode the CLI locator never probes the disk (the dev PC has the user's signed-in claude.exe 2.1.258).
